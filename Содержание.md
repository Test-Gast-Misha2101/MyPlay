# 📑 Содержание

Полная навигация по вазе Obsidian проекта Beta_Unity.

## Основные страницы

- [00 — Обзор проекта](00 — Обзор проекта.md) — дерево `Ai\Scripts`, таблица всех скриптов
- [Архитектура (README)](README.md) — иерархия классов, потоки руды, индекс сцены, динамический UI (mermaid)

## Ядро (Core)

- [Config](Классы/Config.md) — индекс сцены, API регистрации объектов
- [MainSystemTrigers](Классы/MainSystemTrigers.md) — шина событий (триггеров)
- [World_commands](Классы/World_commands.md) — фундамент: сетка, JsonP, ошибки, абстрактные классы
- [Core_Spawn](Классы/Core_Spawn.md) — спавн ядра и игрока, инициализация GUI

## Данные (Data)

- [Sattings_block_cr](Классы/Sattings_block_cr.md) — ScriptableObject блоков для постройки
- [Create_block](Классы/Create_block.md) — структура ResursesCraft (рецепт крафта)
- [BaseDate](Классы/BaseDate.md) — реестр руд (BaseDateOre)

## Машины (Machines)

- [Move_class](Классы/Move_class.md) — корпус машины: точки входа/выхода, соседи
- [Conveir](Классы/Conveir.md) — конвейер (очередь из 3 слотов)
- [Mine_ore](Классы/Mine_ore.md) — добытчик руды + топливо
- [Core_res](Классы/Core_res.md) — ядро-склад ресурсов

## Руда (Ore)

- [Ore](Классы/Ore.md) — компонент рудного блока на сцене
- [ORE_BLOCK](Классы/ORE_BLOCK.md) — описания руд (New_ore) и поиск руд в сцене

## Игрок (Player)

- [Move_person](Классы/Move_person.md) — движение и камера игрока
- [Created_block](Классы/Created_block.md) — постройка блоков (рейкаст + призрак)
- [ButtonCreateBlock](Классы/ButtonCreateBlock.md) — кнопка UI → постройка

## Интерфейс (Gui)

- [ManagerGuiCr](Классы/ManagerGuiCr.md) — JSON-менеджер UI
- [PrefabGui](Классы/PrefabGui.md) — шаблоны GUI (заготовка)

## Ввод (Input)

- [ControllerButton](Классы/ControllerButton.md) — Tab, курсор, блокировка клавиш

## Утилиты (Utils)

- [World_Types](Классы/World_Types.md) — Dic_Rdic, двунаправленный словарь
- [WorldGoDisasamble](Классы/WorldGoDisasamble.md) — Blueprint: сериализация GameObject

## Редактор (Editor)

- [BigStringLabel](Классы/BigStringLabel.md) — Drawer для BigStringAttribute
