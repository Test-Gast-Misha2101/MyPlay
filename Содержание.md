# 📑 Содержание

Полная навигация по вазе Obsidian проекта Beta_Unity.

## Основные страницы

- [[00 — Обзор проекта]] — дерево `Ai\Scripts`, таблица всех скриптов
- [[Архитектура]] — иерархия классов, потоки руды, индекс сцены, динамический UI (mermaid)

## Ядро (Core)

- [[Config]] — индекс сцены, API регистрации объектов
- [[MainSystemTrigers]] — шина событий (триггеров)
- [[World_commands]] — фундамент: сетка, JsonP, ошибки, абстрактные классы
- [[Core_Spawn]] — спавн ядра и игрока, инициализация GUI

## Данные (Data)

- [[Sattings_block_cr]] — ScriptableObject блоков для постройки
- [[Create_block]] — структура ResursesCraft (рецепт крафта)
- [[BaseDate]] — реестр руд (BaseDateOre)

## Машины (Machines)

- [[Move_class]] — корпус машины: точки входа/выхода, соседи
- [[Conveir]] — конвейер (очередь из 3 слотов)
- [[Mine_ore]] — добытчик руды + топливо
- [[Core_res]] — ядро-склад ресурсов

## Руда (Ore)

- [[Ore]] — компонент рудного блока на сцене
- [[ORE_BLOCK]] — описания руд (New_ore) и поиск руд в сцене

## Игрок (Player)

- [[Move_person]] — движение и камера игрока
- [[Created_block]] — постройка блоков (рейкаст + призрак)
- [[ButtonCreateBlock]] — кнопка UI → постройка

## Интерфейс (Gui)

- [[ManagerGuiCr]] — JSON-менеджер UI
- [[PrefabGui]] — шаблоны GUI (заготовка)

## Ввод (Input)

- [[ControllerButton]] — Tab, курсор, блокировка клавиш

## Утилиты (Utils)

- [[World_Types]] — Dic_Rdic, двунаправленный словарь
- [[WorldGoDisasamble]] — Blueprint: сериализация GameObject

## Редактор (Editor)

- [[BigStringLabel]] — Drawer для BigStringAttribute
